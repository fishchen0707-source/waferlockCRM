# 師傅端流程盤點 — 缺了哪些環節

> 2026-08-14　·　**只談流程，不談系統**
> 骨架用「交接點」而不是時間軸——流程斷掉的地方，永遠在一個人交給下一個人的那一刻。

---

## 先講結論

一張單從業務手上走到師傅裝完，中間有 **7 個交接點**。
目前**只有 3 個有人負責**，其餘 4 個靠「大家自己會注意」。

```
業務 →① 助理 →② 倉庫 →③ 貨運 →④ 師傅 →⑤ 客戶
                                    ↘⑥ 回報公司
                                       公司 →⑦ 客戶（進度）
```

| 交接點 | 現況 |
|---|---|
| ① 業務 → 助理 | ✅ 有（email＋訊息），但沒有「收到了」的回應 |
| ② 助理 → 倉庫 | ✅ 有（貼群組），但**倉庫得自己去翻** |
| ③ 倉庫 → 貨運 | ✅ 有 |
| ④ **貨運 → 師傅** | 🔴 **完全沒有人負責**。這是最大的洞 |
| ⑤ 師傅 → 客戶 | 🟡 有約時間，但三方喬的過程沒留下 |
| ⑥ 師傅 → 公司 | ✅ 有（到場、施工、照片、簽名） |
| ⑦ 公司 → 客戶 | 🔴 沒有。客戶只能打電話問業務 |

---

## 🔴 洞一：貨到師傅手上，沒有人管

貨不是寄給客戶，是寄到**師傅或鎖店**。但這段完全沒有人負責：

- **沒有人告訴師傅「貨什麼時候到」** — 大榮／新竹出貨後一到兩天會到，這件事沒人講
- **沒有人確認「師傅收到了」** — 貨運簽收單是貨運公司的，公司這邊不知道
- **沒有人核件數** — 倉庫說業助也不知道要幾件，只能大概估
- **師傅排安裝日期是用猜的** — 猜早了貨沒到，白跑一趟

> 你說「師傅查出貨流程」——師傅真正要問的不是出貨單號，是
> **「我的料到了沒、幾件、什麼時候可以去裝」**。

**要補的**：預計到貨日通知師傅、師傅簽收（含件數）、貨到才可排安裝。

---

## 🔴 洞二：師傅站在客戶家裡發現缺料，沒有路可走

撿錯料是會發生的（料號很長，只看前後就會拿錯左右向）。
但現在只有**月底對帳**才會發現，而師傅是**當下**站在現場。

沒有定義的事：

- 現場發現少一支／型號不對，跟誰講？
- 補的那一趟算不算新的一次出貨？
- 運費誰吸收？
- 師傅這趟白跑，工資怎麼算？
- 客戶那邊誰去解釋、誰去重約？

---

## 🔴 洞三：客戶完全問不到進度

客戶想知道「什麼時候來裝」，只能打給業務；業務問助理；助理問倉庫。
**一路人傳人，每一段都是打斷別人工作。**

這條鏈上沒有任何一個人的工作是「回答客戶進度」。

---

## 🔴 洞四：要通知師傅，得先知道師傅是誰

- **外包師傅名冊不存在**（中區訪談明講）。簡報上寫「全台約 140 位」，**這個數字沒人查證過**
- 沒有名冊，就沒有聯絡方式，「通知師傅」這件事第一步就斷了
- 而且師傅不是同一種人：**內部工班／外包師傅／鎖店／門廠師傅**，
  能看什麼、能接什麼案子都不一樣
- 中區與北南的職能也不同：中區做安裝＋工地協調＋丈量＋維修；
  北南只做維修售服，**安裝是門廠師傅在做**

---

## 🔴 洞五：客戶資料現在攤在群組裡

業務把客戶姓名、電話、地址貼在師傅 LINE 群。
**群裡每一位師傅都看得到所有客戶的個資**，包括不是他負責的案子。

改成一對一通知，這件事本身就是個流程改動。

## 其他斷掉或沒定義的環節

### 出發之前

| 缺什麼 | 現在怎麼運作 |
|---|---|
| **場勘／丈量** | 中區工務有在做，但那是**另一趟行程**，沒有單、沒有排程 |
| **要帶哪些零件** | 師傅憑經驗 |
| **進不進得去** | 工地門禁、電梯預約、管委會報備、工地安全講習——建案這項沒處理就白跑 |
| **多久要回覆接不接** | 沒有時限。師傅不回，案子就卡著 |

### 現場

| 缺什麼 | 說明 |
|---|---|
| **客戶不在家** | 白跑。誰認定、算不算車馬費 |
| **現場條件不符** | 門厚度不對、電源沒拉、孔沒開。停工怎麼記、何時再來 |
| **改期** | 客戶臨時改、師傅臨時有事，誰通知誰、誰去跟另外兩方講 |
| **教客戶使用** | 有沒有標準？漏教會變成後續報修 |

### 裝完之後

| 缺什麼 | 說明 |
|---|---|
| **序號要綁到客戶** | 沒有這一步，日後報修查不到這支鎖是誰的、什麼時候裝的 |
| **保固從哪天算** | 目前只有一種算法（驗收當天），但實際有三種：合約案使照後 2～3 年、經銷出貨日起算 1 年、分批出貨用大貨日 |
| **雙重保固** | 我方對經銷一年、經銷對業主兩三年——**請款對象因此不同** |
| **簽回單** | 誰去追、收在哪、沒收回會不會影響收款 |
| **師傅的工資** | 師傅看不到自己請到哪一階段、這個月累積多少 |
| **包材與舊鎖** | 誰帶走、算誰的 |

### 售後

| 缺什麼 | 說明 |
|---|---|
| **維修要領料** | 領了哪些零件、算在哪一張報修單上，現在沒有串 |
| **退貨換貨** | 走什麼流程，一訪完全沒問到 |
| **是誰裝的** | 客訴時要能回頭查安裝紀錄做責任歸屬 |

## 兩個現行規則自相矛盾（要有人決定）

1. **收費金額**：系統現在**強制必填**，但北區說「不能強迫師傅填收款金額」
2. **保固起算**：系統只認一種，實際有三種

---

## 建議先補的五個

| 順序 | 補什麼 | 為什麼是它 |
|:--:|---|---|
| 1 | **師傅名冊** | 第 0 步。沒有名冊，後面全部不用談 |
| 2 | **預計到貨日告訴師傅** | 最便宜。出貨日加一到兩天，資料本來就有，馬上有感 |
| 3 | **師傅簽收（含件數）** | 有了它，排安裝才不是用猜的 |
| 4 | **群組改一對一通知** | 個資風險，而且改起來不難 |
| 5 | **現場缺件回報** | 已知會發生的事，卻沒有處理路徑 |

## 還沒問到、但會影響整張圖的事

- ~~電商（MOMO／蝦皮／官網）的單走哪一條路？~~ **已部分回答（2026-08-14，業助新訓教材）**：
  電商訂單走的是**同一套核心流程**（客戶訂單→料號庫存查詢→訂單程式→出貨程式→應收帳款→
  通知出貨群組），只是「客戶」換成平台本身、由電商課助理處理。實際合作平台不只 MOMO／蝦皮，
  還有 **PCHOME、燦坤、特力屋、HOMEBOX、Pinkol**。**仍未回答**：這些單需不需要經過師傅安裝，
  或哪些品項是純出貨不裝機——這點原始訓練教材沒寫，要問電商課實際操作的人。
- **建案跟散戶的流程一不一樣？** 建案有工地、有分批、有使照
- **鎖店的案子師傅怎麼分？** 鎖店自己有師傅嗎
- **退貨換貨走哪裡？**
- **師傅該不該看到自己的工資？** 看得到會不會衍生別的問題
