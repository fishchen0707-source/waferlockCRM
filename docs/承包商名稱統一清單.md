# 承包商名稱統一清單

> 由 `scripts/analyze-shipment-history.py` 的同源資料產出（工資發包申請單，全部業務分頁）。
> 目前承包商欄共 **154 種寫法**、3478 筆發包。
>
> **為什麼要做這件事**：接 LINE 通知之後，系統要靠承包商名稱去查「這位師傅的群組是哪一個」。
> 名稱不一致 → 查不到群組 → **師傅收不到通知，而且沒人會發現**。
> 現在的後果只是報表統計被拆成兩筆；接了 LINE 之後會變成貨到了師傅不知道。

## 整理完之後要做的兩件事

1. 把保留的寫法填進「選單」分頁的承包商欄，讓下單頁的下拉只出現這些。
2. 把試算表裡的舊值改成一致。**⏎ 標記的那幾筆有換行字元**，肉眼看不出來但程式比對一定失敗，要一併清掉。

> ⚠️ 系統**刻意不自動合併**——合併錯了會讓工資對到錯的人，也會讓通知送到錯的師傅。這份清單只是建議，要人確認。
