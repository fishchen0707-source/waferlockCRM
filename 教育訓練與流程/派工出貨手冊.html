派工出貨系統 操作手冊

從業務下單到倉庫出貨，四個角色接力。這本手冊按角色分章——先找到你自己那一章，把它讀完就能開始用。
最後兩章是給想弄懂全貌的人：一整條流程走一遍看自己那一步影響誰，常見問題是實際會跳出來的錯誤訊息。

開始之前：怎麼進系統、你會看到什麼

系統沒有帳號密碼，用你的公司 Google 帳號自動辨識身分。用私人 Gmail 開會顯示沒有權限。

網址　script.google.com/a/macros/waferlock.com/s/…/exec　（請向資訊人員索取完整網址並加入書籤）

最上面那排頁籤，每個人看到的不一樣

你看得到哪幾個頁籤，取決於你被登記在哪份名單裡：

角色你需要用到的頁籤登記在哪
業務下單、查詢路由對照表的「業務信箱」欄
助理首頁、出貨登錄、查詢指令碼屬性 DISPATCH_ASSISTANTS

這本手冊的截圖會出現全部 8 個頁籤。 截圖是用一個看得到所有頁籤的帳號拍的，而且目前部分名單還沒設定——名單是空的時候系統會退回「不擋任何人」， 所以你現在可能也看得到八個。照你上表那一列做就好，其他頁籤不用管。 倉庫核單頁最上面若出現黃色的「⚠ 尚未設定 DISPATCH_WAREHOUSE」，講的就是這件事，不是你操作錯誤。
業務請直接把下單頁加書籤。 直接開總網址的話，系統會照「簽核 → 出貨登錄 → 倉庫核單」的順序找你能進的頁， 這個順序裡沒有下單頁，所以純業務身分開總網址會看到「您沒有簽核權限」。 把網址結尾加上 ?page=order 存成書籤就不會遇到。

Chat 通知會自己找上你

你不必一直守著這個網頁。該你做的事會用 Google Chat 通知你，訊息裡都有一個藍色連結， 點下去就直接開到那一筆，不用自己再去清單裡找。

聊天室誰要看會收到什麼
助理出貨群組助理、業務核准後的認領卡片、倉庫回報有問題、退單申請
倉庫出貨群組倉庫待撿料出貨、核單後的備存訊息
派工小幫手（應用程式）所有人可以直接問它問題，例如「查金宏鎖店的單」

業務：下單業務

下單頁把三種下單方式放在同一頁，用最上面那排按鈕切換。單別要先選——它決定下面出現哪些欄位、以及這張單要不要經過主管簽核。

單別什麼時候用要簽核嗎
發包安裝要派師傅去裝的要，送出後進主管簽核佇列
料件出貨只出料、不派工不用
📷 截圖下單經銷商在 LINE 上丟訂單截圖給你不用
下單頁選「發包安裝」後的完整表單。上面那排是單別按鈕，選了才會展開下面的欄位。
切到「料件出貨」的樣子：沒有承包商欄位，因為料件出貨不派工。單別選錯就會看到不該填的欄位。

怎麼填

  1. 點最上面的頁籤 下單。
  2. 在「單別」那排點 發包安裝（或 料件出貨）。下面的欄位這時才會出現。
  3. 發包資訊：客戶、型號、報價單數量 三個是必填；發包安裝還一定要填 承包商。 案名與承包商是下拉選單，清單裡沒有的就選最後一項「其他」，旁邊會冒出文字框讓你自己打。
  4. 出貨項目：從 TipTop 整段複製貼上，一行一項，含料號與數量。這一格填了，助理就不用重打——這是整條流程最省力的一格。
  5. 送貨資料：貨要送到哪。注意這裡常常是鎖店，不是客人家。
  6. 客人資料：最終消費者。客人姓名／電話／地址加上工項與施工時段，會組成給師傅的通知。
  7. 按綠色的 📝 建立發包單。
填好的樣子（這裡用【驗收測試】資料示範）。發包單號不用填，送出後系統自動編號。
送出成功會顯示「已建立 FC-260826-01（發包安裝），已送主管簽核。」並清空表單。
看到「未寫入：某某欄位」的橘字提醒不要忽略。 那表示你的業務分頁沒有那一欄，你填的內容沒有被存下來。系統不會偷偷吞掉，但也不會幫你補—— 需要那個欄位的話，請資訊人員在你的分頁加上。
送出後不必守著。主管核准後，Chat 的「助理出貨群組」會自動出現一張卡片給助理接手。你不用去催。

業務：截圖下單業務

經銷商在 LINE 丟訂單截圖給你的時候用這個，不用把截圖上的字一個一個打進表單。

在下單頁點「📷 截圖下單」切換過來。
  1. 點 📷 截圖下單。
  2. 按 選擇檔案 選那張截圖。沒選就按辨識會跳「請先選擇圖片」。
  3. 按 🔍 辨識，等系統把截圖讀成欄位。
  4. 逐項核對。讀不到的欄位會留空，自己補上；讀錯的直接改。
  5. 一張截圖有多筆訂單時，按 ＋ 新增品項 補上其他筆。
  6. 確認無誤後按 📦 送出。
辨識結果一定要自己看過再送。 系統讀的是圖片上的字，模糊、遮住、手寫都可能讀錯。送出後就進正式流程了， 錯的資料會一路傳到倉庫。核對這一步不能跳。
截圖下單走的是另一條路：它發的是案件號、不寫發包單號、而且一律免簽核，直接進助理的鍵單清單。

業務：查自己的單業務

查詢頁。一個框查全部，不用先選要查什麼。

發包單號、出貨單號、客戶、案名、客人姓名、電話、通路訂單編號——任一個關鍵字都能查。

查出來是一張完整歷程卡：下單 → 簽核 → 出貨 → 倉庫核單，每一步是誰、什麼時候做的都在上面。
  • 「⏳ 待核」還在主管那邊。
  • 「出貨 ⏳ 尚未出貨」助理還沒鍵 TipTop 單號。
  • 「倉庫 已核」倉庫已經撿完料。
  • 要取消已經送出的單，按卡片上的 🔄 申請退單，助理會收到通知。
卡片下方的 📋 複製師傅通知 會把不含金額的施工資訊複製起來，直接貼進師傅的 LINE 群組就好。

助理：從 Chat 認領助理

主管核准後，「助理出貨群組」會自動出現一張卡片。這是你的工作來源，不必自己去清單裡撈。

剛出現的卡片：狀態是「⏳ 待認領」。
  1. 看到卡片後，先按 ✋ 我來處理。這一步是給其他助理看的，避免兩個人同時做同一筆。
  2. 卡片會變成「🔵 你的名字 處理中」，並附上時間。
  3. 再按 ➡ 開這一筆鍵單，會直接跳到那一筆的鍵單畫面。
按下去之後：狀態變「🔵 Fish Chen 處理中 08/26 13:48」，「我來處理」按鈕消失。
忘了按「我來處理」也不會壞。只是別人不知道你在做，可能會重複。養成先按的習慣。

助理：補 TipTop 單號助理

業務已經下過單的，資料都是現成的，你只要補三格。

從 Chat 卡片點進來的單筆畫面。上半部灰色區是業務填的，不能改也不用改。
  1. 先在 TipTop 把這筆單開好，拿到出貨單號與訂單編號。
  2. 回到這個畫面，把 出貨單號（必填，格式 W5501-…）填進第一格。
  3. 訂單編號（W5301-…）填第二格。
  4. 出貨日期 填第三格，格式 2026/08/26。
  5. 按 📦 鍵入並通知倉庫。
三格填好的樣子。上面的出貨項目是業務貼的，直接拿去 TipTop 用，不必重打。
送出後會出現「已鍵入 …，已通知倉庫撿料」，下面還附了一段師傅通知。
那段師傅通知按一下就複製。 按 📋 複製師傅通知，直接貼到師傅的 LINE 群組。內容刻意不含金額，可以放心貼。
出貨單號送出後就不能改了。 按下去的同時倉庫就收到通知了。填錯的話請倉庫按「⚠ 有問題」退回來，或直接找資訊人員。

助理：舊流程——自己填整張助理

兩種情況要走這裡：業務還沒用下單頁（單子只有發包、沒有出貨資料），或是根本沒有發包單的出貨（弱電料件、鎖胚、建案整批）。

出貨登錄頁由上而下三段：① 業務已下單只要補單號　② 已核准待出貨（舊流程）　③ 最下面的完整表單。
  1. 有發包單的：在中間「已核准待出貨（舊流程）」清單裡點那一筆，客戶與案名會自動帶進下面的表單。
  2. 沒有發包單的：略過清單，直接填最下面的表單，發包單號那格留空。
  3. 必填是 出貨單號 與 出貨品項。品項從 TipTop 整段複製貼上即可。
  4. 填貨指寄的收件人／電話／地址，選發票別。
  5. 按 📦 登錄並通知倉庫。
最上面若出現紅色的「倉庫回報有問題」區塊，那是最優先的——在你處理完之前，那筆貨是停住的。 改好之後按「送回倉庫」，它會帶著倉庫寫的問題說明重新出現在倉庫的清單裡。

主管：簽核主管

業務送出「發包安裝」後會進你的簽核佇列，Chat 也會通知你。

簽核頁。每張卡片列出承包商、客戶、型號與承包總價，下面兩顆按鈕。
從 Chat 通知點進來會直接停在那一筆，不必在清單裡找。
  1. 看承包商與承包總價是否合理。
  2. 沒問題按 ✅ 核准；有問題按 ❌ 退回。
  3. 退回要填原因，那句話會原封不動送回給業務——寫清楚可以少一次來回。
處理完會顯示「這一筆已完成，可以關掉這個頁面了 👍」。
簽核者身分取自你的 Google 帳號，不能改。每一筆核准／退回都寫進試算表的「簽核紀錄」分頁。 清單底下若寫「另有 N 筆待副主管核准」，那些不在你的權限範圍，不用管。
清單有最多 15 分鐘的快取。 業務剛開的單可能還沒出現在你的清單裡，但你自己剛簽的一定會立刻反映。看不到新單先等一下，不是壞了。

主管：儀表板與報表主管

首頁：待副主管／待主管／待出貨／待核單各幾筆，以及最舊的一筆等了幾天。

「最舊 N 天」是用來抓卡住的單的。數字異常大就表示有東西卡在那一關沒人動。

報表頁：待辦積壓、出貨趨勢、各業務、各承包商，最下面是需要人工處理的資料不一致。
報表只有主管看得到，因為它會顯示毛利。 毛利一旦露出來就等於把進價反推出來了，所以是整頁限制，不是遮欄位。
最下面那塊「疑似同一承包商的不同寫法」要有人處理。 同一家承包商被寫成兩種寫法，統計就會被拆成兩筆。系統刻意不自動合併——合併錯了會讓工資對到錯的人。 請在「選單」分頁統一寫法，再把試算表裡的舊值改成一致。

倉庫：核單與發票倉庫

助理鍵完 TipTop 單號後，「倉庫出貨群組」會收到一則待撿料出貨。

Chat 通知。出貨單號、客戶、出貨項目、貨指寄、發票別都在上面，最下面藍字「直接開這一筆核單」點下去就到。
倉庫核單頁的完整清單，等著撿的都在這裡。也可以不從 Chat 進來，直接開這一頁往下做。
核單畫面。上半是要撿的東西，中間是發票登錄，最下面兩顆按鈕。
  1. 照「出貨項目」的料號與數量撿料。
  2. 有發票的話，把號碼填進 發票號碼（格式 AB-12345678），或用 發票電子檔 選檔案上傳，兩個都填也可以。
  3. 按 ⬆ 登錄。會出現「已登錄發票號碼 …，核單時會一起送出」。
  4. 撿完料按 ✅ 已撿料完成。
發票登錄成功的樣子。這一步可以跳過——沒有發票就直接按已撿料完成。
按下已撿料完成後，Chat 會收到一則完整的備存訊息，含登錄人與核單人的時間戳。
核完之後再開同一筆會顯示「這一筆已經處理過了（已核）👍」，並列出是誰、什麼時候核的。
發票要在按「已撿料完成」之前登錄。備存訊息是核單那一刻產生的， 先按完成再登錄發票，那則備存訊息裡就不會有發票資料了。

倉庫：回報有問題倉庫

料號對不上、數量不對、地址明顯有誤——不要自己猜著出，按 ⚠ 有問題。

  1. 按 ⚠ 有問題。
  2. 填問題說明（必填）。寫具體一點，助理是照這句話去改的。
  3. 送出後這筆會先從你的清單消失，交給助理處理。
  4. 助理改好按「送回倉庫」，它會帶著你寫的問題說明重新出現在你的清單裡，你可以確認是不是真的改對了。
「有問題」會同時通知助理與業務。不是丟到黑洞裡，會有人接。

倉庫：貨運單上傳倉庫

貨運單頁。新竹物流、嘉里大榮的 PDF 都可以。
  1. 點頁籤 貨運單。
  2. 按 📤 上傳 選 PDF。一份檔案裡有好幾張出貨單沒關係，系統會自動拆開。
  3. 上傳完就可以離開，不必留在這一頁等，辨識要幾分鐘。
對不上的不會亂猜。配不到出貨單的會列進「貨運單待指定」分頁，由人工指定。 系統刻意不用猜的——猜錯的貨運單號看起來完全正常，之後查不出來。

一整條流程走一遍

這一章不是操作步驟，是給你看自己那一步影響誰。下面是一筆單從頭到尾實際走過的樣子。

#誰做什麼做完之後會發生什麼
1業務下單頁選「發包安裝」，填完送出系統編號（例 FC-260826-01），進主管簽核佇列
2主管簽核頁按「核准」助理出貨群組出現一張認領卡片
3助理Chat 按「我來處理」卡片變「處理中」，其他助理知道有人接了
4助理去 TipTop 開單，回來補三格單號倉庫出貨群組收到「待撿料出貨」；同時產生師傅通知
5倉庫登錄發票、按「已撿料完成」Chat 收到完整備存訊息，這筆結束
6任何人查詢頁輸入單號看到整條歷程：誰在什麼時候做了什麼
走完之後在查詢頁看到的樣子——上面六步全部在這一張卡片上。
兩件事值得記住：
① 業務在出貨項目那一格貼的東西，助理直接拿去用。業務多花十秒貼完整，助理就少打十五個欄位。
② 每一步都有 Chat 通知，所以不需要有人「去問進度」。要查就自己開查詢頁，比問人快。

常被問到的

Q：我送出的單多久會出現在主管那邊？
清單有最多 15 分鐘快取，所以主管可能不會馬上看到。但主管自己剛簽的一定立刻反映。

Q：填錯了怎麼辦？
還沒送出就直接改。已經送出的：業務用查詢頁的「🔄 申請退單」；已經鍵單的請倉庫按「⚠ 有問題」退回來給助理改。

Q：為什麼我看得到八個頁籤，手冊說我只有兩個？
因為部分角色名單還沒設定，名單是空的時候系統會退回「不擋任何人」。照你那一章做就好。

Q：Chat 通知裡的連結點不開？
確認你是用公司 Google 帳號登入的瀏覽器開。用私人 Gmail 開會顯示沒有權限。

Q：一張截圖裡有好幾筆訂單怎麼辦？
辨識完後按「＋ 新增品項」逐筆補上，不要分成好幾次上傳同一張。
